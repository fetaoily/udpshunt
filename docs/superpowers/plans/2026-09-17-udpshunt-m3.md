# udpshunt M3 (Performance) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver M3 of udpshunt — Linux batch receive (`recvmmsg` via a build-tagged pktio layer), pooled hot-path buffers, lock-free balancer reporting, configurable `SO_RCVBUF`, a benchmark suite with an honest performance report — plus every M2-final-review item deferred to M3.

**Architecture:** A new `internal/pktio` package wraps the frontend socket: on Linux one `recvmmsg` drains up to 64 packets per wakeup (via `golang.org/x/net` `ReadBatch`); elsewhere it degrades to a single blocking `ReadFromUDP`. Downstream relay buffers move from one-per-goroutine (64KB × sessions) to a `sync.Pool` held only for the read→write span. The balancer's per-packet `ReportError`/`ReportSuccess` mutex is replaced by atomic per-backend counters and a copy-on-write pool pointer, removing the last hot-path lock (spec §7). SO_REUSEPORT is explicitly benchmark-then-decide (spec: 视结果), with the decision documented in `docs/benchmarks.md`.

**Tech Stack:** Go stdlib, `gopkg.in/yaml.v3`, `github.com/prometheus/client_golang`, `go.uber.org/goleak`, **new:** `golang.org/x/net` (spec §1/§7 name it explicitly; Linux-only import behind a build tag).

**Spec:** `docs/superpowers/specs/2026-09-15-udpshunt-design.md` — this plan implements §11 milestone M3 (§7 performance engineering).

```go
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	port := ln.Addr().(*net.TCPAddr).Port
	ln.Close()

	s := New(fmt.Sprintf("127.0.0.1:%d", port), Deps{
		Registry: prometheus.NewRegistry(),
		Status:   func() Status { return Status{} },
		Reload:   func() error { return nil },
		Logger:   slog.Default(),
	})
	ctx, cancel := context.WithCancel(context.Background())
	done := make(chan error, 1)
	go func() { done <- s.Run(ctx) }()

	deadline := time.Now().Add(2 * time.Second)
	up := false
	for time.Now().Before(deadline) && !up {
		resp, err := http.Get(fmt.Sprintf("http://127.0.0.1:%d/status", port))
		if err == nil {
			resp.Body.Close()
			up = true
		} else {
			time.Sleep(10 * time.Millisecond)
		}
	}
	if !up {
		t.Fatal("server did not come up within 2s")
	}
	cancel()
	select {
	case err := <-done:
		if err != nil {
			t.Fatalf("Run returned error: %v", err)
		}
	case <-time.After(2 * time.Second):
		t.Fatal("Run did not return after cancel")
	}
}
```

**Design notes for the implementer:**
- The Listener keeps its `pc *net.UDPConn` field (downstream writes and Close keep working unchanged) and gains an `io *pktio.Conn` used ONLY by `Run`'s receive loop and the ctx watcher (`SetReadDeadline`).
- Linux receiver picks `ipv4.NewPacketConn` vs `ipv6.NewPacketConn` once at `Wrap` time from the bound address family (`LocalAddr().(*net.UDPAddr).IP.To4() != nil` → v4). `ReadBatch` honors the socket read deadline on Linux (internal/socket converts it to the recvmmsg timeout); the linux-only cancellation test below proves it in CI.
- Batch size: `const recvBatchSize = 64` in listener.go. The batch buffers (`recvBatchSize × MaxPacketSize` = 4 MiB per listener) are allocated ONCE per `Run` from one backing array.

```go
// Package pktio wraps UDP sockets with platform-optimal receive batching:
// one recvmmsg per wakeup on Linux, one packet per wakeup elsewhere.
package pktio

import (
	"net"
	"time"
)

// MaxPacketSize is the largest UDP payload a buffer must hold.
const MaxPacketSize = 65536

// Conn wraps a frontend UDP socket for batched receiving.
type Conn struct {
	pc    *net.UDPConn
	batch batchReceiver
}

// batchReceiver is the platform receive implementation (build-tagged files).
type batchReceiver interface {
	// ReceiveBatch blocks until at least one packet is available, then
	// reads up to len(bufs) packets. addrs and sizes receive the source
	// address and payload length of every packet. It honors the socket's
	// read deadline.
	ReceiveBatch(pc *net.UDPConn, bufs [][]byte, addrs []*net.UDPAddr, sizes []int) (n int, err error)
}

// Wrap prepares pc for batched receiving.
func Wrap(pc *net.UDPConn) *Conn {
	return &Conn{pc: pc, batch: newBatchReceiver(pc)}
}

// ReceiveBatch reads a platform-optimal batch of packets.
func (c *Conn) ReceiveBatch(bufs [][]byte, addrs []*net.UDPAddr, sizes []int) (int, error) {
```

```go
// The reporting path (ReportError/ReportSuccess) and Pick/Snapshot are
// lock-free: per-backend counters and state are atomics, the pool and
// options are copy-on-write atomic pointers (spec §7: no hot-path locks).
package balancer

import (
	"sync/atomic"
	"time"
)

const (
	defaultCooldown = 10 * time.Second
	defaultFall     = 3
	defaultRise     = 2
)

// Options configures the balancing algorithm and health state machine.
// The zero value behaves like M1: round_robin, fall 3, passive cooldown
// recovery.
type Options struct {
	Balance      string        // round_robin | least_sessions | source_hash
	Fall         int           // consecutive errors before down (default 3)
	Rise         int           // consecutive successes to recover (default 2)
	Cooldown     time.Duration // passive recovery cooldown (default 10s)
	ActiveChecks bool          // true: recovery needs Rise successes (no cooldown path)
	// Counts reports the live session count per backend (least_sessions
	// only). It is called during Pick and must not re-enter the Balancer.
	Counts func(addr string) int64
}

// BackendState is a point-in-time view of one backend.
type BackendState struct {
	Addr    string
	Healthy bool
}

type backend struct {
	addr         string
	healthy      atomic.Bool
	errCount     atomic.Int64
	successCount atomic.Int64
	downSince    atomic.Int64 // unix nanoseconds
}

type pool struct {
	list   []*backend
	byAddr map[string]*backend
}

type Balancer struct {
	pool    atomic.Pointer[pool]
	opts    atomic.Pointer[Options]
	next    atomic.Uint64
	onState atomic.Pointer[func(addr string, healthy bool)]
}

func (b *Balancer) fire(fn *func(addr string, healthy bool), addr string, healthy bool) {
	if fn != nil {
		(*fn)(addr, healthy)
	}
}

func (b *Balancer) onStateFn() *func(addr string, healthy bool) { return b.onState.Load() }

// New creates a balancer over addrs.
func New(addrs []string, opts Options) *Balancer {
	if opts.Fall <= 0 {
		opts.Fall = defaultFall
	}
	if opts.Rise <= 0 {
		opts.Rise = defaultRise
	}
	if opts.Cooldown <= 0 {
		opts.Cooldown = defaultCooldown
	}
	if opts.Balance == "" {
		opts.Balance = "round_robin"
	}
	b := &Balancer{}
	o := opts
	b.opts.Store(&o)
	b.Update(addrs)
	return b
}
```
